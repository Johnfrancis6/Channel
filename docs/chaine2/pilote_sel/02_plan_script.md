# Plan du script — pilote « le sel » (29/09/2026)

**Statut : plan en temps, pas encore le texte.** Le texte s'écrira après
la comparaison des transcriptions (un succès, un raté, Je T'explique Comment,
Zenn), comme demandé par Franco. Ce plan applique le modèle mesuré sur *le
fer* (CONTEXTE §2) et l'angle validé le 29/09 : **« le trésor devenu
gratuit »**, le mythe du salaire comme moment « comment on le sait », la fin
sur ce qu'on fait du sel aujourd'hui.

Budget : **environ 1 480 mots, 8 min à environ 3,1 mots/s**. Hook de 25 à
30 s, 10 temps de 120 à 150 mots, fin sur une question ouverte, pas d'appel
à s'abonner. Les renvois (1.2, 3.3…) pointent vers les affirmations de
[`01_recherche.md`](01_recherche.md).
