# Photos d'exemple pour le banc d'essai

Dépose ici des photos prises à l'iPhone (JPEG). Le banc d'essai Playwright
(`npm run qualite`) les passe toutes dans la détection des bords et l'OCR, et
écrit un rapport dans `rapport-qualite/` (non commité ; en CI il est publié
comme artefact du workflow).

**N'y mets que des documents sans données personnelles** (menu, page de
livre, prospectus…) : ce dossier est commité. Pour des photos privées, utilise
`exemples/prive/`, ignoré par git.
